# Portfolio DECK

Minimal, sleek investment portfolio dashboard with a standalone Windows executable.

## Features
- **Multi-asset tracking:** Crypto (CoinGecko + CoinMarketCap backup + Yahoo Finance fallback), Equities, Funds, and Commodities (Yahoo Finance + optional Alpha Vantage / Finnhub).
- **Interactive charts:** Portfolio balance curve (USD / EUR / BTC toggle), Top 3 Allocation treemap + full-page Allocation Map, and individual full-page Asset Detail charts.
- **Dedicated Watchlist:** Track assets you don't own alongside watched holdings.
- **Privacy & Themes:** Light / Dark mode toggle and Hide Balances blur.
- **Local persistence:** User data is stored in `user_data/` next to the app, starting from 0 assets.

## Run
- **Windows:** Download `PortfolioDECK.exe` from [Releases](https://github.com/kopykatA/Portfolio-DECK/releases) and double-click it.
- **From source (Node.js):** `node server.js` and open `http://localhost:4173`.
